## 🚀 Sobre o Repositório

Este repositório contém todos os projetos, exercícios e desafios práticos que desenvolvi ao longo da trilha de conhecimento. O objetivo é registrar minha evolução, desde os conceitos fundamentais de C# e .NET até a construção de aplicações completas com React no front-end e a implantação em nuvem com Azure.

Cada projeto demonstra a aplicação prática dos conceitos teóricos aprendidos durante a formação.

* **Versionamento:** Uso profissional de Git e GitHub para controle de versão e colaboração.

## 🚀 Como Executar um Projeto

A maioria dos projetos neste repositório são aplicações de console ou APIs. Para executá-los, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/mcastroif/DIO-NET-Course.git](https://github.com/mcastroif/DIO-NET-Course.git)
    ```

2.  **Navegue até a pasta do projeto desejado:**
    ```bash
    cd DIO-NET-Course/pasta-do-projeto
    ```

3.  **Execute o projeto usando a CLI do .NET:**
    ```bash
    dotnet run
    ```
    *Para projetos de API, o comando `dotnet watch run` é recomendado para iniciar o servidor. Para projetos front-end em React, utilize `npm install` seguido de `npm start`.*
