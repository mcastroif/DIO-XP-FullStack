## 🚀 Sobre o Repositório

Este repositório contém todos os projetos, exercícios e desafios práticos que desenvolvi ao longo da trilha de conhecimento da formação Full-Stack .NET. O objetivo é registrar minha evolução, desde os conceitos fundamentais de C# e do ecossistema .NET até a construção de APIs RESTful robustas e aplicações completas.

Cada projeto demonstra a aplicação prática dos conceitos teóricos aprendidos durante o curso.

## 🚀 Como Executar um Projeto

A maioria dos projetos neste repositório são aplicações de console ou APIs. Para executá-los, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/mcastroif/DIO-NET-Course.git](https://github.com/mcastroif/DIO-NET-Course.git)
    ```

2.  **Navegue até a pasta do projeto desejado:**
    ```bash
    cd DIO-NET-Course/pasta-do-projeto
    ```

3.  **Execute o projeto usando a CLI do .NET:**
    ```bash
    dotnet run
    ```
    *Para projetos de API, o comando `dotnet watch run` é recomendado para iniciar o servidor e recarregá-lo automaticamente após alterações no código.*
